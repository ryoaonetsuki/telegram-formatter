Supported markup

**bold**   __italic__ or *italic*   `code`   > quote line   [text](https://example.com)   - list item   # Heading line

Why pasting markdown fails in Telegram

Telegram's message box does not render markdown pasted as plain text. If you copy **bold** from a code block or a plain-text file, Telegram shows the asterisks literally. This tool instead puts formatted HTML on the clipboard, so Telegram receives the formatting itself — the same way copying from a formatted document works.
