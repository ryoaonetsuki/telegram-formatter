About the free AI

AI Chat and AI Post Writer use the Pollinations free text API — a real third-party shared service, not our own model, and not unlimited. It needs no API key and stores nothing here, but it can be slow or busy at times. If it fails, you will see the error and a retry button — replies are never faked.
