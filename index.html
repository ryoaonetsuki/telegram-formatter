About the free AI

AI Chat and AI Post Writer use the free Pollinations API (plain GET, no API key, no sign-up, no popup) — a real third-party shared free service, not our own model, and not unlimited. Nothing is stored here, but replies can be slow or busy at times. If it fails, you will see the error and a retry button — replies are never faked.

Design

Designed as a premium dark product interface — solid refined panels, hairline borders, restrained accent color, and clear typography. Icons: Lucide (MIT) for UI, Simple Icons (CC0) for brand marks. An earlier version used the solid-glass design system (MIT); that styling no longer ships.

TG Toolkit — free to use, no sign-up, no data collected. Source: github.com/ryoaonetsuki/telegram-formatter (MIT). Design: custom dark product design (v3).
